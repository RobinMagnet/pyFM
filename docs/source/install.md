Installation
============

This package is pretty minimal and should run on all machines. It supports
Python 3.10+.

With pip
--------

```bash
pip install pyfmaps
```

Plotting
--------

The plotting helpers in {mod}`pyFM.viz`, used throughout the
[example gallery](auto_examples/index), are optional and pull in PyVista:

```bash
pip install 'pyfmaps[viz]'
```

From source
-----------

```bash
git clone https://github.com/RobinMagnet/pyFM.git
cd pyFM
pip install -e .
```
